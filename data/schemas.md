# 训练数据格式

统一使用 UTF-8 编码的 JSONL：每行一个完整 JSON 对象。示例只说明结构，不代表真实数据已经准备或审查完成。

## 继续预训练（CPT）

```json
{"text":"一段医学领域文本，使用前需审查来源、质量和使用许可。"}
```

对文本执行下一个 token 预测。本次 CPT 实际使用此格式。

## 监督微调（SFT）

```json
{"conversations":[{"from":"human","value":"这个系统可以代替医生吗？"},{"from":"gpt","value":"不能。它只能提供一般信息，具体问题需专业人员评估。"}]}
```

包含用户提问与期望回答。训练前需核验上游读取格式、聊天模板和损失掩码。本项目尚未完成 SFT。

## 奖励模型偏好数据

```json
{"question":"信息不足时怎样回答？","response_chosen":"说明不确定之处，必要时提出澄清问题。","response_rejected":"编造缺失信息并给出确定结论。"}
```

chosen 表示较优回答，rejected 表示较差回答。这是早期设计示例，字段需要按实际选择的训练脚本核验，奖励模型和强化学习流程尚未跑通。

## 数据隔离

训练、验证、最终测试和 C-Eval 应分别存放，仍需进一步检查内容重复。来源与处理状态见[数据卡](DATA_CARD.md)。
